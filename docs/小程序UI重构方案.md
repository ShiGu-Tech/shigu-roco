# 洛克王国 PVP 助手 · 小程序 UI 重构方案

## 一、产品定位

**核心用户：** 玩家在 PVP 对战时需要快速决策辅助  
**核心场景：** 拍照识别当前局面 → 秒级推荐最优行动  
**核心卖点：** 离线运行 + 不读内存 + 算法透明（不是外挂）

## 六、技术要点

### 1. 小程序限制适配

- 包体积 < 2MB（分包加载）
- Worker 支持（算法在 Worker 运行）
- 图片压缩（拍照后压到 1600px）
- localStorage → wx.storage

### 2. 性能优化

- 首屏 < 1s（bundle.json 预加载）
- 推演计算 < 3s（MCTS 迭代次数降级）
- 离线可用（数据包内置）

### 3. 兼容性

- iOS / Android
- 微信版本 >= 8.0
- 基础库 >= 2.19.0

## 九、现有代码可复用清单

✅ 完全复用：
- `modules/engine/**` - 战斗引擎（纯 TS）
- `modules/battle/types.ts` - 类型定义
- `data/*.json` - 规则与机制数据

⚠️ 需适配：
- `modules/board/` - 对战逻辑（去掉 React 依赖）
- `modules/pets/` - 精灵管理（改 wx.storage）

❌ 不复用：
- shadcn/ui 组件 → 微信小程序原生组件
- Next.js 路由 → 小程序 Page/Component
- `/api/engine/*` → 独立 API 服务
