## 二、后端 API 重构

### 现状分析

当前 ShiGuRock 是 **Next.js App Router** 架构：
- 前端：React Server Components
- 后端：`app/api/**/*.ts` (Route Handlers)
- 引擎：Web Worker（浏览器端）

**问题：**
1. API Routes 耦合 Next.js，小程序无法直接调用
2. 引擎在浏览器 Worker 里，无法复用
3. 没有统一的 RESTful 接口

### 重构方案：独立 API 服务

#### 方案 A：渐进式改造（推荐）

**保留 Next.js Web 版，新增独立 API 层**

```
D:\ShiGuRock\
├─ apps/
│  ├─ web/  (现有 Next.js，保留)
│  └─ api/  (新建独立 API 服务)
│     ├─ src/
│     │  ├─ routes/
│     │  │  ├─ ingest.ts    (POST /ingest/photo)
│     │  │  ├─ battle.ts    (POST /battle/recommend)
│     │  │  └─ catalog.ts   (GET /catalog)
│     │  ├─ services/
│     │  │  ├─ engine.ts    (引擎调用封装)
│     │  │  └─ ingest.ts    (识别逻辑)
│     │  └─ server.ts
│     ├─ package.json
│     └─ tsconfig.json
├─ packages/
│  └─ engine/  (引擎抽离为独立包)
│     ├─ src/
│     │  ├─ simulator/
│     │  ├─ mcts/
│     │  └─ index.ts
│     └─ package.json
└─ data/  (数据文件共享)
```

**优势：**
- Web 版继续用，不影响现有用户
- API 服务独立部署，可给小程序/移动端用
- 引擎代码复用，不重复维护

#### 技术选型

| 组件 | 技术栈 | 原因 |
|------|--------|------|
| **API 框架** | Fastify | 性能好、TS 支持完善、插件生态丰富 |
| **引擎运行时** | Node.js Worker Threads | 复用现有 TS 代码，多核并行 |
| **数据存储** | JSON 文件 + Redis（可选） | 保持离线优先，Redis 缓存热数据 |
| **图片识别** | tmxk-vision API | 复用现有接入 |
| **部署** | Docker + PM2 | 与现有基础设施一致 |

### 4.3 关键代码示例

#### 拍照识别（index.ts）

```typescript
// miniprogram/pages/index/index.ts
import { compressImage } from '../../utils/compress';
import { ingestPhoto } from '../../utils/request';

Page({
  data: {
    loading: false,
  },

  async onTapPhoto() {
    try {
      this.setData({ loading: true });

      // 1. 选择图片
      const res = await wx.chooseMedia({
        count: 1,
        mediaType: ['image'],
        sourceType: ['album', 'camera'],
      });

      // 2. 压缩
      const compressed = await compressImage(res.tempFiles[0].tempFilePath);

      // 3. 识别
      const result = await ingestPhoto(compressed);

      // 4. 跳转到对战页
      wx.navigateTo({
        url: `/pages/battle/battle?data=${encodeURIComponent(JSON.stringify(result))}`,
      });
    } catch (err) {
      wx.showToast({ title: '识别失败', icon: 'error' });
    } finally {
      this.setData({ loading: false });
    }
  },
});
```

#### API 封装（utils/request.ts）

```typescript
// miniprogram/utils/request.ts
const API_BASE = 'https://api.shigu.zone';

interface IngestResult {
  player: Array<{ spriteId: string; name: string }>;
  enemy: Array<{ spriteId: string; name: string }>;
}

export async function ingestPhoto(image: string): Promise<IngestResult> {
  return new Promise((resolve, reject) => {
    wx.request({
      url: `${API_BASE}/api/ingest/photo`,
      method: 'POST',
      data: { image, compressed: true },
      success: (res) => {
        if (res.statusCode === 200 && res.data.success) {
          resolve(res.data);
        } else {
          reject(new Error(res.data.error || '识别失败'));
        }
      },
      fail: reject,
    });
  });
}
```

## 五、核心引擎复用

### 5.1 抽离为独立包

```typescript
// packages/engine/src/index.ts
export { Simulator } from './simulator/battle';
export { search as mctsSearch } from './mcts/search';
export { buildBundle, getBundle } from './data';
export type { 
  BattleState, 
  Action, 
  Recommendation 
} from './types';
```

### 5.2 在 API 服务中使用

```typescript
// apps/api/src/services/engine.ts
import { Simulator, mctsSearch, getBundle } from '@shigu-rock/engine';

export async function recommend(state: BattleState, options: MCTSOptions) {
  const bundle = await getBundle();
  const simulator = new Simulator(bundle);
  
  const result = await mctsSearch(simulator, state, {
    iterations: options.iterations ?? 1000,
    maxDepth: options.maxDepth ?? 12,
  });

  return {
    recommendations: result.actions.map((a, i) => ({
      action: a,
      winRate: result.winRates[i],
      rank: i + 1,
    })),
  };
}
```

### 5.3 在小程序中本地运行（可选）

如果要**完全离线**，可以把引擎编译到小程序 Worker：

```typescript
// miniprogram/workers/engine.ts
import { Simulator, mctsSearch } from './engine-bundle'; // Webpack 打包

worker.onMessage((msg) => {
  if (msg.type === 'recommend') {
    const result = mctsSearch(simulator, msg.state, msg.options);
    worker.postMessage({ type: 'result', data: result });
  }
});
```

**权衡：**
- ✅ 完全离线，无需服务器
- ❌ 小程序包体积暴增（引擎 + 数据 ~5MB）
- ❌ 手机算力受限，MCTS 迭代次数少

**建议：先做 API 版，后期按需优化。**
