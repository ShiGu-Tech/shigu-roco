# 引擎能力总览 · v0.1

> 文档状态：设计 ✅ v0.1 · 代码 ✅ · 验证 ✅ · 生产 ✅
>
> 上游：《引擎边界-设计-v0.1》（引擎核心 / 数据层 / 表现层）、《引擎版本与维护-设计-v0.1》（`ENGINE_VERSION` 与 bump 策略）、《战斗机制扩展层-设计-v0.1》（触发器 / 条件 / 效果 DSL）、《能耗与技能修正-设计-v0.1》（能耗域）。
>
> 用途：**引擎提供哪些"能力"的总清单**。具体技能 / 特性 / 印记 / 状态 / 天气一律由数据注册调用；引擎内不含任何具体 id、名字或倍率。现行 `ENGINE_VERSION 0.12.0`。

## 1. 定位

引擎 = **通用状态修改器执行器 + 决策层**：把「触发器 + 条件 + 效果原语组合」安全地作用到战斗状态上，并在结算中读「有效状态 / 有效规则」；再据此做回合推演与动作推荐。

## 2. 触发器（何时）

| 阶段 | 触发器 |
| --- | --- |
| 开局 | `battleStart` |
| 回合 | `turnStart` / `turnEnd` / `battleEnd` |
| 行动声明与排序 | `actionDeclared` / `beforeActionOrder` / `actionOrderResolved` / `beforeAction` / `actionResolved` |
| 伤害 | `beforeDamage` / `afterDamage` / `onHit` |
| 换人 | `beforeSwitch` / `afterSwitch` / `onEntry` |
| 生死 | `beforeDeath` / `afterDeath` |
| 效应用后 | `beforeEffect` / `afterEffect` |
| 领域事件 | `skillUsed` / `statusApplied` / `markApplied` / `weatherChanged` / `skillCooldownReduced` |
| 规则读取 | `passive`（按需求值，不计次） |

## 3. 条件

`allOf` / `anyOf` / `not` + 单条件 `{ path, op, value? , valueFrom? }`；`op` = `eq` / `neq` / `gt` / `gte` / `lt` / `lte` / `in` / `has` / `contains`。`path` 为点路径，可读状态 / 事件 / 派生值。

## 4. 动态数值 `DynamicValue`

点路径 + `scale` / `offset` / `round`；路径末尾 `*` 合计对象数值；非线性用 `terms` 多项式（如 `N²+24N−24`）。`deltaFrom` / `valueFrom` / `powerFrom` / `hitsFrom` / `percentFrom` / `amountFrom` 等入口按当前状态求值。

## 5. 效果原语（按域）

| 域 | 原语 |
| --- | --- |
| 生命 | `dealDamage`（公式 / 固定 / `maxHp` / `currentHp` / 按层 + `element` + `powerFrom`）、`heal` |
| 属性 | `modifyStat`（flat / percent + 上限）、`clearStat`（驱散 / 偷取，`stat` / `polarity` / `limit`） |
| 伤害修饰 | `modifyDamage`（出 / 承伤、乘 / 加）、`setHits`（连击）、`setDamageReduction`（减伤） |
| **能耗** | `modifySkillCost`（`scope` 单技能 / 攻击 / 防御 / 全 + `elements` / `excludeElements`；`delta` / `multiply` / `mode`；`duration` = permanent / turns / nextAction / aura；`oncePerTurn` / `hidden` / `dispellable`）、`clearCostMod` |
| 印记 | `applyMark` / `setMark` / `scaleMark` / `transferMark` / `transformMark` / `removeMark` / `consumeMark`（每层效果 + 消耗合计） |
| 状态 | `applyStatus`（含 `immuneElements`）/ `setStatus` / `scaleStatus` / `settleStatus`（DoT / 衰减）/ `removeStatus` |
| 天气 | `changeWeather`（带 `turns`） |
| 冷却 | `modifyCooldown`（可按 `skillIdFrom` 动态取） |
| 能量 / 魔力 | `modifyEnergy`（可 `deltaFrom`）/ `modifyMagic` |
| 换人 | `forceSwitch` / `escape` / `allowSwitch` / `modifySwitchLock` |
| 入场继承 | `scheduleEntry`（下个入场队列）/ `inheritStat` |
| 技能池 | `learnSkill` / `forgetSkill` / `replaceSkill` / `randomizeSkill` / `swapSkillSet` |
| 行动队列 | `setPriority` / `forceFirst` / `insertAction` / `cancelAction` / `replaceAction` |
| 记忆 / 计数 / 修正 | `addCounter` / `setCounter` / `clearCounter` / `modifySkill`（威力 / 能耗 / 连击 / 先手持久修正） |
| 规则覆盖 | `setRuleModifier`（`passive` 通道，覆盖 `rules.*`，如印记上限 / 异种互斥） |

## 6. 通用机制（横切）

- **有效能耗统一读取** `effectiveCost(state, bundle, side, skillId)`：`base × Πmultiply + Σdelta` → `floor`（省能耗方向）→ `clamp ≥ 0`；执行 / `legalActions` / 预览 / Worker **同源**。
- **时效**：`permanent`（到本场结束）/ `turns`（回合末 −1）/ `nextAction`（该侧下次行动后移除）/ `aura`（来源在场即生效，来源离场回收）。
- **每回合限次** `oncePerTurn`（回合开始重置，按 `side:机制` 触发一次）。
- **概率** `chance`（确定性种子，同状态同种子可复现）。
- **元素免疫** `immuneElements`；**级联**（`applyStatus` / `applyMark` 深度上限）；**事务化事件**（每次修改产出事件明细，供 UI / 日志 / 回放）。
- **来源与可见性**：条目带 `source` / `sourceId`、`hidden`（隐藏来源）、`dispellable`（名义 debuff 可驱散 / 特性造成不可）。

## 7. 决策层

- `Simulator`：`step`（四阶段回合结算）/ `legalActions` / `terminal` / `forcedSwitch`。
- `MCTS` 推演 + **贝叶斯对手模型 / 养成后验**。
- `recommend`：输出各动作预估胜率与理由。
- 浏览器 **Web Worker** 前台计算；`/api/engine/*` 仅兜底与管理。

## 8. 与数据 / 版本的边界

- **数据驱动**：技能 / 特性 / 印记 / 状态 / 天气 = 「触发器 + 条件 + 原语组合」，写在 `data/mechanisms.json`、`data/rules.json` 等；引擎不含具体内容。
- **独立版本** `ENGINE_VERSION`（现行 `0.12.0`）：只有新增通用能力（新触发器 / 新效果命令 / 新结算时机）才 bump；数据有各自版本（图鉴 `registrationId` · `dataVersion`、`data/*.json` 的 `version`）。
