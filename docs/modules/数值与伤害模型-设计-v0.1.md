# 数值与伤害模型（洛克王国底层机制）· 设计 v0.1

> 文档状态：设计 ✅ v0.1 · 代码 ✅（面板等级公式已接入；星陨 / 特性倍率表除外）· 验证 ✅（面板）/ 🟡（伤害与其余）· 生产 ✅

## 1. 定位与边界

把《洛克王国世界》的**真实数值换算**与**伤害结算**沉淀为引擎的底层机制，替代此前 `stats.ts` / `damage.ts` 的占位实现（宝可梦式、数值口径不对）。

本稿覆盖：

1. **面板真实数值**：种族资质 / 个体资质 / 性格 / 等级 60 的换算（PVP 口径）。
2. **伤害主公式**：攻防真实数值 + 战时显示威力 + 平衡系数 + 减伤 + 连击。
3. **各项加成倍率**：本系、属性克制（含双系）、强化差值、特性、减伤。
4. **数据契约**：`data/stats.json` / `data/rules.json` 的新结构；属性倍率配置（`values` / `combine`）随图鉴归一化产出（`engine/catalog/normalize.ts`）。

不在本稿范围：

- **星陨**：属印记机制，后续注册到印记效果（`marks` / 机制扩展层）。
- **特性表**（勇敢 / 圣火骑士 / 偏振等 30+ 条）：本稿只留数据驱动的倍率入口，具体表另稿。
- 回合顺序、技能效果 DSL、MCTS（各自模块稿）。

## 2. 设计原则

1. **公式即数据**：所有系数落 `data/*.json`（属性倍率随图鉴归一化），代码只做解释器；实测校准 = 改数据。
2. **PVP 归一**：PVP 常见基准为 **60 级 + 5★**；面板由「种族 + 个体（天分×星级）+ 性格 + 等级」直接换算，星级加成另计。
3. **可复现**：纯函数、整数舍入规则明确（四舍五入 / 向下取整）。
4. **未确认处显式标注**：双系混合、特性表、强化层存储等标 `【待校准】`，不伪装成确定事实。

## 3. 领域模型

### 3.1 资质（静态）

| 名称 | 来源 | 说明 |
| --- | --- | --- |
| 种族资质（种族值） | 图鉴写死（`catalog.sprites[].race`，现查） | 同种一致，六维 |
| 个体资质（天分） | 运行时 `StatProfile.iv` | 天分 **1~10**；每升一星加一倍，满星 5★ = ×6 → **IV 0~60**；只加 **3 项**、每项 ≤ +60 |

### 3.2 养成档案（`StatProfile`）

```ts
interface StatProfile {
  level?: number;                 // PVP 固定 60（可省）
  nature?: string | null;         // 性格 id（stats.json.natures）
  iv?: Record<string, number>;    // 个体值：hp/atk/spatk/defense/spdef/speed，各 0~60
}
```

> 旧的「三维（体力/攻击/防御）培养面板 + perPoint」模型**废弃**。

### 3.3 面板真实数值（`stats.ts`）

> 来源：官方图卡「roco pet – RocoDiviner」口径 + **实测等级公式**（多精灵逐级面板 + 游戏内「每级提升」）。面板**含等级项**。

```text
攻 / 防 / 速   面板(L) = round( 性格 × round( 10 + (种族 + 个体×0.5) × (L+50)/100 ) )
生命           面板(L) = round( 性格 × round( 10 + 0.5·种族 + 0.2·个体 + (1 + 0.02·种族 + 0.01·个体) × L ) )
```

- `round` 两次：括号内先四舍五入一次，乘性格后再四舍五入一次。
- 性格乘在括号上；星级加成（见下）另算，不参与性格。
- 系数全部落在 `data/stats.json.panels`（`hp` / `default`），可校准。

**每级提升（不含性格，即游戏内显示的「每级 +x」）：**

```text
攻 / 防 / 速 ： (种族 + 个体×0.5) / 100
生命        ： 1 + (2·种族 + 个体) / 100        ← 攻防速斜率的 2 倍 + 恒定 1
```

**关键结构：**

- 攻防速的 `(L+50)/100` 在 L60 恰好 = 1.1，即图卡的 ×1.1 口径；`(L+50)` 也让低等级保留一块「底板」。
- 个体（三维）是括号内独立项、随等级线性放大。
- 生命项系数约为攻防速对应项的 2 倍，再加每级恒定 `+1`。
- 等价展开：`攻防速 = 10 + 0.5·种族 + 0.25·个体 + (0.01·种族 + 0.005·个体)·L`（与 `data/stats.json.panels.default` 的 6 系数一一对应）。

**实测校验（2026-09-28，逐项对拍全中）：**

| 精灵（性格 / 三维） | 等级 | 面板：生命/物攻/魔攻/物防/魔防/速度 |
| --- | --- | --- |
| 十字蝌蚪（+魔攻-速度，魔攻+9/物防+10/魔防+7） | 18 | 86 / 68 / 42 / 61 / 48 / 50 |
| 苞米仔（+魔防-物防，物攻+10/物防+10/魔防+10） | 42 | 175 / 87 / 84 / 86 / 106 / 65 |
| 足尖元件（+生命-物防，生命+8/物防+10） | 15 | 111 / 36 / 67 / 49 / 72 / 75 |
| 蜜果骸（+生命-速度，生命+10/物防+8/速度+10） | 41 | 211 / 49 / 110 / 76 / 87 / 86 |
| 蝴蝶陶陶（+速度-物攻，物攻+9/物防+10/速度+9） | 43 | 131 / 63 / 25 / 75 / 63 / 92 |

> 更早的锚点（石肤蜥 / 矿晶虫 L1+L36、布灵 L38~60、小鼠獭 L12、护主犬 / 绿翼鸟 / 丢丢 L1）也已并入同一公式回验，逐级残差 ≤1。

**星级（面板加成）：** 每星生命 **+20**、其他五项 **+10**（0★ = 0，5★ = `+100 / +50`，即图卡末尾常数）。

> `【待校准】`：星级加成是否随等级缩放未知；本轮实测全部为 0★。

### 3.4 性格（`stats.json.natures`）

- **正面 ×1.1、负面 ×0.9、中性 ×1.0 —— 六项统一（生命不再单独 ×1.2）。**
- 性格乘在括号上，且**先取整括号、再乘性格**；星级加成不受性格影响。
- 性格改变 → 整体重算（无状态，与升级先后无关）。

> ⚠️ `【待校准】`：图卡图例「迪莫 大胆(物攻+20%)」的 ×1.2 与实际 ×1.1 冲突（布灵 60 级 0★ 生命 = `188×1.1 = 207` 命中，若 ×1.2 则为 226）；名称→属性映射仍需按游戏核实。

## 4. 伤害模型

### 4.1 主公式

```text
伤害 = floor( (攻 × 战时显示威力 × 37/41) ÷ 防 ) × 减伤 × 连击

战时显示威力 = 技能威力 × 克制 × 本系 × 攻方特性 × 防方特性 × 强化差值 × 其他
```

- 攻 = 真实物攻 或 魔攻（物理 / 魔法取对应）；防 = 真实物防 / 魔防。
- `37/41 ≈ 0.9024`：平衡系数。
- `floor` 向下取整。

### 4.2 各项倍率

| 项 | 规则 |
| --- | --- |
| 本系 | 技能属性 = 精灵属性 → ×1.25；不一致 → ×1.0 |
| 属性克制 | 双重克制 ×3、单倍克制 ×2、普通 ×1、单倍抵抗 ×0.5、双重抵抗 ×0.25 |
| 强化差值 | `1 + 0.1×攻方层 − 0.1×防方层`（攻+3 ≡ 防−3 ≡ ×1.3） |
| 特性 | 数据驱动倍率表（攻方 / 防方），内置 30+ 条；图卡举例：勇气 ×1.4、圣火骑士 ×2.0、偏振 ×0.6；默认 1.0 |
| 减伤 | `1 − 减伤%/100`，上限 99% |
| 连击 | 命中段数，默认 1 |

**双系混合规则**（`【待校准】`，与上表一致的最小实现）：

```text
weak  = 防方属性中，本攻击属性为「克制」的个数（0~2）
resist= 防方属性中，本攻击属性为「抵抗」的个数（0~2）
克制项 = weak=0 → 1；weak=1 → 2；weak=2 → 3
抵抗项 = resist=0 → 1；resist=1 → 0.5；resist=2 → 0.25
克制倍率 = 克制项 × 抵抗项
```

> 例：火 vs [草, 水] = 1 弱 1 抗 = `2 × 0.5 = 1.0`，与旧测试一致。

### 4.3 强化差值与 buff 存储

- `buffs[stat]` / `debuffs[stat]` 存**分数**，一层 = 0.1（`+0.3` ≡ +3 层）。
- 强化差值 = `1 + (攻方 buff+debuff) − (防方 buff+debuff)`，攻/防属性取对应物理 / 魔法项。
- 伤害中的攻/防用**纯面板数值**（不含 buff）；buff 只通过强化差值进伤害。
- 速度 / 展示用 `effectiveStat = 面板 × (1 + buff + debuff)`（保留）。

### 4.4 星陨（占位）

```text
星陨威力 N = N² + 24N − 24   （1层=1、5层=121、10层=316）
星陨伤害 = floor( round(攻 × 星陨威力 × 幻系克制 × 特性 × 强化差值 × 37/41) ÷ 防 ) × 减伤
```

> 归入**印记**机制，后续注册到印记效果，不在本稿实现。

## 5. 数据契约

### 5.1 `data/stats.json`

```jsonc
{
  "level": { "default": 60 },
  "panels": {
    // panel(L) = round( 性格 × round( base + 种族×raceBase + 个体×ivBase
    //                                  + (levelBase + 种族×raceSlope + 个体×ivSlope)×L ) )
    "hp":      { "base": 10, "raceBase": 0.5, "ivBase": 0.2,  "levelBase": 1, "raceSlope": 0.02, "ivSlope": 0.01 },
    "default": { "base": 10, "raceBase": 0.5, "ivBase": 0.25, "levelBase": 0, "raceSlope": 0.01, "ivSlope": 0.005 }
  },
  "starBonus": { "hp": 20, "default": 10, "starMax": 5 },
  "individual": { "starMultiplier": 6, "maxPerStat": 60, "starMax": 5, "investCount": 3 },
  "natures": [ { "id": "adamant", "up": "atk", "down": "spatk", "upFactor": 1.1, "downFactor": 0.9 } ],
  "trainingProfiles": { "options": [ { "id": "full", "label": "满个体", "prior": 1, "iv": { "hp": 60, "atk": 60, "speed": 60 } } ] }
}
```

> `level` 是面板换算的输入（缺省 60）；`panels.default` 的 6 系数即 `10 + (种族 + 个体×0.5)×(L+50)/100` 的展开，`panels.hp` 为生命公式。星级加成 = `星级 × (+20/+10)`，另计、不参与性格。

### 5.2 `data/rules.json.damageFormula`

```jsonc
{ "kind": "roco_v1", "balance": 0.9024390244, "stab": 1.25 }
```

### 5.3 属性倍率（图鉴归一化产出）

- 不再有 `data/elements.json` 静态文件；由 `engine/catalog/normalize.ts` 在注册图鉴时写入 `bundle.elements`（`elements` 属性表 + `matrix` 克制矩阵 + 下列配置）。
- `values`：`counter=2 / counter3=3 / neutral=1 / resisted=0.5 / resisted4=0.25`。
- `combine`：`{ mode: "count", clampTo: [0.25, 3] }`。

## 7. 关键决策

| 决策 | 选择 | 理由 |
| --- | --- | --- |
| 等级 | 面板含等级项：攻防速 `10+(种族+个体×0.5)×(L+50)/100`、生命 `10+0.5种族+0.2个体+(1+0.02种族+0.01个体)L` | 多精灵逐级面板 + 游戏「每级提升」全中；L60 退化回图卡 ×1.1 |
| 个体建模 | 天分×星级，IV 0~60，限 3 项；括号内独立项、随等级线性放大 | 来自官方图例 + 实测 |
| 性格 | 六项统一 ×1.1 / ×0.9，乘在括号上（先取整再乘） | 布灵 `188×1.1=207`、足尖元件 `101×1.1=111` 命中；图卡图例 288 的 ×1.2 不成立 |
| 双系 | 计数规则（弱+1 / 抗×0.5） | 与给出的 5 档表一致 |
| 特性 | 只留数据驱动入口 | 30+ 条特性表另稿 |

## 8. 非目标

- 不做真实等级成长曲线（PVP 固定 60）。
- 不实现特性表与星陨（另稿）。
- 不引入暴击 / 命中 / 随机浮动（本项目非外挂、可复现优先）。

## 9. 待校准 / 待确认

1. 性格名称→属性映射（图卡「大胆 物攻+20%」与实际 ×1.1 冲突，需按游戏核实）。
2. 双系混合的混合情形（1 弱 1 抗）以 `2×0.5=1` 实现，需真机确认。
3. 特性倍率表数据（30+ 条）。
4. 连击 / 减伤的数据来源（技能 / 印记 / 特性）。
5. 强化层上限与衰减规则。
6. 星级加成（每星 +20 / +10）是否随等级缩放——面板公式未含星级，本轮校验全部为 0★。
7. 面板逐级取整细节：括号先取整再乘性格已确认；个别点残差 ±1（如流明坎德拉 L37 生命 222 vs 实测 223），待更多样本收敛。
