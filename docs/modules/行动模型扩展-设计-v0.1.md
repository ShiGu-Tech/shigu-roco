> 定位：补齐**改「行动」契约**才能表达的能力——**选择（明/暗）**、**蓄力（延迟释放）**、以及支撑「奉献」所需的**技能 tag（啃咬 / 虫群）**。这些会改动 `Action` 结构、`legalActions`、对战台输入与 MCTS 落子，故单独立稿。

## 1. 定位与边界

- **目标**：让「一个行动」能表达子选择（选择）与跨回合待释放（蓄力）；让技能带可查 tag（奉献的目标集合）。
- **不在本稿**：伤害/结算主公式；纯数据转写（走《内容补齐》批次）；面板。
- **原则**：引擎只认**通用行为**（`choice` 通道 / `pendingSkill` 队列 / `tags` 字段），具体技能与参数全在数据。

## 2. 现状与缺口

- 当前 `Action`（`apps/web/src/modules/engine/types.ts`）：`{ kind: "skill" | "energy" | "switch"; skillId?: string; benchId?: string }` —— **无子选择、无待释放**。
- 缺口条目（第三期 C0-7/C0-8/C0-10）：
  - **选择 21 条**：振翅 / 野火 / 补觉 / 超声波 / 蒸汽进行曲 / 沙石阵 / 马步 / 龙守望 / 薄纱环 / 捷足先登 …
  - **蓄力 9 条**：龙吟 / 架势 / 龙守望 / 龙血 / 极寒领域 …
  - **奉献 5 条 + 特性**：虫结阵 / 虫群智慧 / 振翅 / 假寐 / 信息素（目标 = 带「啃咬 / 虫群」tag 的技能）。

## 3. 领域模型

### 3.1 行动加「子选择」

```ts
type Action =
  | { kind: "skill"; skillId: string; choice?: 0 | 1 }   // 选择：0=明 1=暗
  | { kind: "switch"; benchId?: string }
  | { kind: "energy" };
```

- 数据侧：技能效果按 `event.action.choice` 分两组（或用 `variants[choice]` 数据）。
- 事件：`actionDeclared` / `beforeAction` / `skillUsed` 的 `event.action.choice` 暴露当前选择。
- UI：对战台技能按钮对「选择技」弹二选一（行内二段按钮 / `Dialog`），默认明。
- `legalActions`：对选择技列出 `choice:0` 与 `choice:1` 两条。
- MCTS：在选择技处扩展两个分支（等同「两招」）。

### 3.2 蓄力（待释放技能队列）

```ts
interface ActiveSprite {
  pendingSkill?: { skillId: string; choice?: 0 | 1 };  // 已蓄力、下回合自动释放
}
```

- **使用**蓄力技：本次不产生其效果，改为设 `pendingSkill`；`switchLock += 1`（蓄力期间免疫离场）。
- **下回合**：在行动结算时，若 `pendingSkill` 存在，则**以之替换/插入**该侧行动自动释放（无需玩家输入），释放后清空并解除离场锁。
- 事件：新增 `skillCharged` / `skillReleased`（或复用 `skillUsed` 带 `charged` 标记）。
- UI：显示「蓄力中 · 下回合释放」徽章；该侧本回合行动受限（可选：允许换人以外的动作，待校准）。
- 决策（待校准）：蓄力当回合是否可以再行动、蓄力期间被强制换人如何处理、蓄力技与「传动 / 巧变」的交互顺序。

### 3.3 技能 tag

```ts
interface DataBundle["skills"][id] { tags?: string[] }   // 由图鉴 glossary / desc_id 解析写入
```

- tag：`蓄力 charge` / `迸发 burst`（已有事件）/ `传动 shift`（已有）/ `巧变 improvise`（已有）/ `选择 choice` / `啃咬 bite` / `虫群 swarm`。
- 引擎只把 tag 当**查询面**（如奉献按 tag 选目标）；不含具体技能名。

### 3.4 奉献（依赖 tag）

```ts
interface SideState {
  dedications?: Array<{ kind: "combo" | "power" | "cost"; value: number }>;
}
```

- 释放「奉献」→ 向己方 `dedications` 入队（随机 / 指定）。
- 带「啃咬 / 虫群」tag 的技能使用前，读取队列并生效（连击 +1 / 威力 +20 / 能耗 −2），消耗对应次数。
- 触发时机：`beforeDamage`（威力 / 连击）与 `beforeAction`（能耗）。

| 面 | 改动 |

## 5. 关键决策

1. **选择 = 行动上的 `choice` 通道**，不为每个选择技造命令。
2. **蓄力 = `pendingSkill` 队列**，复用 `scheduleEffect` 的跨回合思路，但释放是「占用行动」而非「附加效果」。
3. **tag 只作查询面**，不给 tag 写行为分支。
4. **每个动作都可回放**：`choice` / 蓄力释放都进 `Action` 或事件，回放 / 观战无需改记录格式之外的东西。

## 6. 非目标

- 不引入暴击 / 命中随机。
- 不做「选择」的自动决策策略（MCTS 只多两个分支）。
- 不在本稿做特性 213 条转写。
