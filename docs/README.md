# 洛克王国世界 PVP 决策辅助工具 · 文档索引

> 文档唯一入口。项目理解先看《项目全景手册》和《项目状态》。

## 定位一句话

**非外挂**的离线辅助工具：人工录入对局状态 → Python 引擎复刻官方回合结算并做 MCTS 推演 → Next.js 网页展示各动作预估胜率与理由。不读取游戏画面、不自动操作游戏、不联网。

## 文档约定

- 大功能先设计后实施：新增领域模型或结构性改动，先在本目录建独立设计稿，确认后再编码；实施完成后回填同一稿。
- 每份模块 / 架构稿头部必须写明「文档状态」四态：设计 / 代码 / 验证 / 生产。
- 修改文档路径时，同步更新本索引、源码注释、README 与 `AGENTS.md` 中的引用。
- 未定 / 待游戏实测校准的规则，显式标注 `【待校准】`，不要写成确定事实。
