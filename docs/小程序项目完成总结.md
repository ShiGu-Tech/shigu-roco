## 💻 技术要点

### 小程序语法 vs React

**WXML 模板（小程序）：**
```xml
<!-- 条件渲染 -->
<view wx:if="{{show}}">显示</view>

<!-- 列表循环 -->
<view wx:for="{{list}}" wx:key="id">
  {{item.name}}
</view>

<!-- 事件绑定 -->
<button bindtap="handleClick" data-id="123">
  点击
</button>
```

**WXSS 样式：**
```css
/* rpx 响应式单位 */
.button {
  width: 100%;
  padding: 48rpx;  /* 设计稿 750px 宽直接用数值 */
  border-radius: 24rpx;
}

/* 动画 */
@keyframes float {
  0%, 100% { transform: translateY(0); }
  50% { transform: translateY(-8rpx); }
}
```

### 主题系统架构

```
utils/theme.js (主题定义与管理)
    ↓
page data: { theme: {...} }
    ↓
WXML 模板中动态应用 {{theme.colors.*}}
    ↓
用户切换 → themeManager.setTheme() → setData() → UI 更新
    ↓
wx.storage 自动保存选择
```

## 🎓 关键概念解析

### rpx 单位
- 设计稿 750px 宽 = 屏幕 750rpx
- 自动缩放，iPhone 14 Pro 大约 1rpx = 0.524px

### Page 生命周期
```js
Page({
  onLoad(options) { },      // 首次加载
  onReady() { },            // 视图准备完成
  onShow() { },             // 页面显示
  onHide() { },             // 页面隐藏
  onUnload() { },           // 页面卸载
});
```

### setData 更新视图
```js
this.setData({ 
  theme: newTheme,  // 更新后自动触发视图重渲染
});
```

### 主题动态应用
```wxml
<view style="background: {{theme.colors.card}}; color: {{theme.colors.textPrimary}};">
  <!-- {{ }} 双花括号内可以访问 data 中的任何变量 -->
</view>
```

## ✨ 设计亮点回顾

### 为什么选童话黄？

1. **符合洛克王国风格**
   - 官方游戏多用浅色系
   - 童话、梦幻、温暖氛围
   - 不是科技冷色调

2. **用户体验优化**
   - 浅色系降低视觉疲劳
   - 金黄色温暖舒适
   - 阅读时间久不刺眼

3. **技术优势**
   - 简单色系易实现
   - 对比度充足（无障碍）
   - 所有设备显示一致

4. **品牌一致性**
   - 与原有 Web 版风格统一
   - 提升品牌认知度
   - 用户跨端体验连贯
