## 总览

- 阶段：**阶段 1–4 已落地（MVP 可用）**；阶段 3.5「引擎 TS 化 + 养成资质」已落地。阶段 5（自动解析 / 扩充数据 / NN 加速）未开始。
- 版本：`0.7.0`（引擎纯 TS；数据静态化 + 前台计算；机制扩展层 + 技能效果完整化；精灵实例与仓库；**全站浅蓝工具风界面重设计**）。
- 数据：资源数据（精灵 / 技能 / 印记 / 天气 / 属性）一律来自激活图鉴（`data/registry/catalogs/`，由 `scripts/sync-roco-world.mjs` 从 roco.world 现查注册）——现行 `f2bc7789ad9c`：精灵 621 / 技能 579 / 印记 4 / 天气 2；引擎参数（`rules.json` / `stats.json` / `assets.json` / `mechanisms.json`）留在 `data/`（`stats.json` 0.7.0 新增 `talentRecommend` 加点推荐阈值）。服务端 `getBundle()` 装配后经 `GET /api/engine/bundle` 导出为**入仓静态包 `apps/web/public/data/bundle.json`**（剥离 `sourceData`，~1 MB），浏览器 Worker 直接读取；`data/registry/` 仍不入仓。**无静态兜底**，缺激活图鉴且缺静态包时服务端报错。精灵 / 技能为**中文显示名**，属性键恒用英文。
- 数值 / 伤害（底层机制）：按官方图卡「先搞懂：种族值&个体值」「①真实数值怎么算」（roco pet – RocoDiviner）口径 + **实测校准**（音速犬 / 银月狼王 / 冰钻布鲁斯 5★ L60、小星光 0★ L45 逐格对拍全中）。面板含等级项 + 星级常数：攻/防/速 `round(性格 × round(10 + (种族+个体×0.5)×(L+50)/100)) + 10×星级`、生命 `round(性格 × round(10 + 0.5种族 + 0.25个体 + (1+0.02种族+0.01个体)·L)) + 20×星级`；性格六项统一「正向 `1.10 + 0.02×星级`（0★=1.10 … 5★=1.20）/ 负向固定 ×0.9」（生命不再单独 ×1.2），星级常数加在性格之后。伤害 `floor((攻 × 战时威力 × 37/41) ÷ 防) × 减伤 × 连击`。个体值 = 天分(1~10)×星级（每升一星加一倍，5★=×6 → 0~60，限 3 项、每项 ≤ +60）。详见《数值与伤害模型-设计-v0.1》。
- 规则：新增《战斗机制-事实整理-v0.1》，已记录行动排序、技能冷却与应对、养成、状态、印记、天气、换人和信息不完全；具体技能机制与倍率继续按 `【待校准】` 管理。
- 扩展层：《战斗机制扩展层-设计-v0.1》+《技能效果完整化-设计-v0.1》——技能池命令与 8 个触发器派发已实现；本轮补齐**结算底座**：按侧 turnEnd 状态/印记结算（`settleStatus` / `settleMark`，印记 DoT 改为「按持有」条件触发）、状态只存层数、元素免疫（`immuneElements`）、概率（`chance`，确定性种子）、条件逻辑（allOf/anyOf/not + `valueFrom` + `self/target` 作用域）、应对（`actionDeclared` 条件 + `forceFirst`，对手动作经 `event.opponentAction`）、`modifyCooldown scope:defense`、`modifyStat maxStages`、通用 onHit；服务端装配改为**保留作者登记的 skill 机制**（仅对无作者 `dealDamage` 的攻击技能自动生成）。221 条状态/防御技能、40 特性、印记/天气细节仍待逐批转写。

## 数据来源（已确认）

- 唯一数据参考站点：`https://roco.world/zh/`（中文站）；所有动态数据的中文名称、说明、机制词条和图片均以此为准。
- 抓取方式：每页内嵌 `<script id="roco-bootstrap" type="application/json">`，含 `catalog.types`（属性与克制矩阵）与 `page.data`（精灵种族值 / 特性 / 技能）。**无需解析自然语言 HTML**。
- 技能、印记、特性和天气统一注册到 `mechanisms.json`，由触发器、条件和效果命令执行；无法确认的复杂效果登记为 `unsupported`，并保留 `rawText`（中文）供人工校对。
- 原 Python 采集器（`engine/roco_engine/ingest/`）已删除；现由 TS 同步脚本 `scripts/sync-roco-world.mjs` 采集并注册图鉴（`--register` 即激活），静态资源 JSON（`sprites/skills/marks/weather/elements.json`）与 `omni-creatures.json` 已移除。

## 已知限制 / 待校准

1. 数值 / 伤害按官方图卡（RocoDiviner）口径 + **实测公式**（攻/防/速 `10+(种族+个体×0.5)×(L+50)/100`、生命 `10+0.5种族+0.25个体+(1+0.02种族+0.01个体)L`，另加星级常数 `+10×星 / +20×星`，见 `stats.json.panels` / `natureScaling` / `starBonus`）与性格加成（六项统一 正向 `1.10+0.02×星级` / 负向 ×0.9）；`stats.json` 0.6.0 已补齐性格 6 项两两组合（30 条 + 中性，`individual.investCount=3`）；仍 `【待校准】`：星级常数是否随等级缩放（样本仅 L60·5★ 与 L45·0★）、性格系数随星级的线性度（仅 0★/5★ 两端点）、逐级取整个别残差 ±1、特性倍率表（30+ 条）、连击 / 减伤数据来源、强化层上下限、双系混合（1 弱 1 抗按 ×1）、性格中文名→属性映射（`roco.world/zh` 无性格表，30 条里仅 8 条按游戏常见口径命名、其余以「↑X ↓Y」占位）。伤害不使用暴击、命中或随机浮动。
2. 个体值 = 天分(0~10)×星级(5★=×6) → IV 0~60，限 3 项；对手个体档位先验 / 似然带宽为占位 `【待校准】`。
3. 对手养成后验已接入 MCTS（rollout 内采样档位），前端已提供基础养成录入与对手库写入。
4. 能量机制：进场 10、聚能 +5/占回合、上限 10，仍标 `【待校准】`。
5. 魔力机制：上限 4、开局 4、每次阵亡 -1、减到 0 判负，仍标 `【待校准】`。
6. 阵亡换人：引擎不自动换人，前端在对应侧面板内选择上场精灵（`/api/engine/simulate/forced-switch`，不耗回合）。
7. 愿力冲击（全队技能）为占位动作，仅扣次数（2）与 CD（4），无伤害 / 效果数据。
8. 部分复杂技能效果（引爆星陨、能耗修正、永久威力变化）尚未按真实规则实现，统一在 `mechanisms.json` 标记为 `unsupported` 并保留 `params.note`；灼烧「层数减半」已实现（`settleMark decayLayers:half`），其余状态衰减规则仍 `【待校准】`。
9. 数据池为全量图鉴（621 精灵 / 579 技能），非天梯高频精选。
