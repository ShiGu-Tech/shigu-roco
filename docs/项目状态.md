## 数据来源（已确认）

- 站点：`https://roco.world`（官方资料站，`source_locale=zh-Hans`；`/zh` 出简体中文）。
- 抓取方式：每页内嵌 `<script id="roco-bootstrap" type="application/json">`，含 `catalog.types`（属性与克制矩阵）与 `page.data`（精灵种族值 / 特性 / 技能）。**无需解析自然语言 HTML**。
- 技能「效果」由启发式正则从**英文描述**生成 `ops`（应对状态 / 增益 / 印记 / 天气 / 先制 / 连击 / 吸血 / 蓄力），并保留 `rawText`（中文）供人工校对。
- ⚠️ 原 Python 采集器（`engine/roco_engine/ingest/`）随引擎 Python 化下线被一并删除；当前数据为人工维护。若需重新采集，可后续以 TS 重写采集脚本。

## 已知限制 / 待校准

1. 伤害公式（`rules.damageFormula`）、换人速度判定、首领化幅度均 `【待校准】`，需真机对拍。
2. 养成资质（`stats.json` 的 `perPoint`、性格倍率、养成档位 / 似然带宽）全部为占位值 `【待校准】`；三维 = 体力 / 攻击 / 防御 三面板，spatk / spdef / speed 暂不受三维影响。
3. 对手养成后验已接入 MCTS（rollout 内采样档位），但**前端尚未提供养成录入 / 观测回填入口**（对手库读取路径已通，写入 UI 待补）。
4. 能量机制：进场 10、聚能 +5/占回合、上限 10，仍标 `【待校准】`。
5. 魔力机制：上限 4、开局 4、每次阵亡 -1、减到 0 判负，仍标 `【待校准】`。
6. 阵亡换人：引擎不自动换人，前端在对应侧面板内选择上场精灵（`/api/engine/simulate/forced-switch`，不耗回合）。
7. 愿力冲击（全队技能）为占位动作，仅扣次数（2）与 CD（4），无伤害 / 效果数据。
8. 部分技能效果（引爆星陨、层数减半、能耗修正、永久威力变化）尚未在解释器实现，已在数据 `params.note` 标注。
9. 数据池为 handbook #1–#40，非天梯高频精选。
