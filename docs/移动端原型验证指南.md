# 移动端 UI 原型 - 快速验证指南

## 已完成内容

### 页面结构

```
/mobile
├── /            首页 - 拍照识别入口
├── /battle      对战页 - 推荐展示（核心）
├── /manual      手动输入（占位）
└── /history     历史对局（占位）
```

### 核心特性

#### 1. 首页 (`/mobile`)

**设计重点：**
- ✅ 主按钮巨大醒目（拍照识别）
- ✅ 加载状态清晰（识别中... 2-3 秒）
- ✅ 次要入口明确（手动输入 / 历史对局）
- ✅ 底部说明合规性（离线 / 不读内存 / 开源算法）

**交互流程：**
```
点击「拍照识别」→ 2秒加载动画 → 自动跳转到对战页
```

#### 2. 对战页 (`/mobile/battle`)

**设计重点：**
- ✅ 顶部状态栏（回合 / 胜率 / 双方血量）
- ✅ 我方精灵卡（大，包含 HP / 能量 / 增减益）
- ✅ 推荐卡片（排名 + 胜率 + 点击展开详情）
- ✅ 对方精灵卡（小，已见技能）
- ✅ 底部操作（上/下回合）

**推荐卡片层级：**
- 🏆 推荐 #1 - 金色渐变 + 「推荐」徽章
- 🥈 备选 #2 - 银色渐变
- 🥉 备选 #3 - 铜色渐变

**展开详情包含：**
- 预估伤害范围
- 💡 优势（为什么推荐）
- ⚠️ 风险（可能的问题）

### 移动端优化

#### 刘海屏适配
```css
viewport-fit: cover
safe-area-inset-top / bottom
```

#### 触控优化
- 所有按钮最小 44×44px
- 主按钮 active:scale-[0.98] 反馈
- 卡片点击有展开动画

#### 暗色模式
- 所有页面支持 dark: 变体
- 自动跟随系统主题

## UI 改进建议征集

### 需要验证的问题

1. **首页文案是否清晰？**
   - "拍照识别对战画面" 能理解吗？
   - 底部三条说明（离线/不读内存/开源）够不够？

2. **对战页信息密度如何？**
   - 推荐卡片是否太挤？
   - 展开详情需要更多内容吗？

3. **交互是否流畅？**
   - 点击推荐卡展开/收起顺滑吗？
   - 「上回合/下回合」按钮位置合理吗？

4. **颜色和视觉层级**
   - 金银铜三色能区分优先级吗？
   - 红蓝双方色彩够不够醒目？

- React 19
- Tailwind CSS v4

- 页面切换：< 100ms（Next.js 路由）
